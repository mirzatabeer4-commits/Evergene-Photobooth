#  EVERGENE Photobooth

A fun, interactive, ENHYPEN-themed photobooth web application built with React. Choose your favorite member's frame, capture a photo using your camera or upload one from your device, and decorate your pictures with stickers!

##  Features

-  Seven member-themed photobooth frames
-  Camera capture functionality
-  Upload photos from your device
-  Decorative stickers for customizing pictures
-  Responsive design for different screen sizes
-  ENHYPEN-inspired visual theme

##  Built With

- React.js
- JavaScript
- HTML5
- CSS3

## Getting Started

### Prerequisites

- Node.js and npm installed on your computer
- Git installed on your computer

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/mirzatabeer4-commits/Evergene-Photobooth.git
   ```

2. Navigate to the project folder:

   ```bash
   cd enhypen-photobooth
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```

5. Open the local URL shown in your terminal.

## 🌐 Deployment

This project can be deployed using Netlify. Connect the GitHub repository and configure the build settings according to the project.
